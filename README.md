# URL Redirect Manager

A WordPress plugin to create and manage URL redirects from the admin dashboard.

## Features
- Add, edit and delete redirects
- 301 / 302 redirect types
- Clean uninstall (removes table and options)

## Installation
1. Download or clone into `wp-content/plugins/url-redirect-manager`
2. Activate it from Plugins in WordPress admin
3. Go to the plugin's admin page to add redirects
